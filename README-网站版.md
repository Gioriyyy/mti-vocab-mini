# 贸大 MTI 词根词缀学习器 - 网站版

这是一个可以直接部署成网站的版本。

## 你现在有的入口

- [单文件手机版](./手机单文件版.html)

## 推荐部署方式

### Vercel

1. 登录 Vercel
2. 新建项目
3. 上传这个 `mti-vocab-mini` 文件夹
4. 让 `手机单文件版.html` 作为主页

如果你想让它直接叫 `index.html`，我可以下一步帮你把单文件版改名并整理成标准网站入口。

## 这个版本适合什么

- 手机直接打开
- 收藏到桌面
- 长期当作词汇学习网站使用

## 需要注意

- 真正上线后，本地磁盘里的 PDF 链接不会自动变成公网可用
- 如果要把资料也一起上线，需要再把资料文件上传到网站目录里
